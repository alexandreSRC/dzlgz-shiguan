# 大周列国志 · 史馆

> 游戏《大周列国志》的修谱工具 —— **左手翻游戏存档（实录），右手修家谱（谱牒），中间一座桥**。
> 目标：不必再手写家谱，从游戏存档不断自动读取、续写家谱。

Windows 桌面应用（Python + Tkinter），另含一个可选的平板端前端（原生 Kotlin + Compose）。

---

## 这是什么

「史馆」由两个旧项目合并而来：

- **《大周列国志 · 存档阅览器》** —— 纯只读的资料库（全量存档、表族与字段中文化），冻结为「数据源」。
- **《Family tree v2.0》** —— 可编辑的修谱台（家谱树 / 时间轴 / 表格 / 小传），冻结为「谱牒母本」。

合并后的「史馆」取二者本义：**藏史**（实录原样收好，只读不增删）＋ **修史**（在实录之上编一部自己的家谱）。

---

## 核心架构：一档 · 两层 · 一桥

```
游戏（模拟器）存档目录 Save_All_N（原文，一字不动）
   │
   ├──► 【实录层】直读存档（只读铁律：永不落盘）
   │        全量人物 · 多表合并 · 全字段中文化
   │
   └──► 【谱牒层】抽取流水线
            → saves/<谱名>/family.json（可编辑：增删改 / 撤销 / 续谱）
   ▲                    │
   └──────── 桥 ────────┘
     · 锚点：谱牒里的人 code = 存档 Ren_Code
     · 入谱：实录某人 → 写入谱牒；查档：谱内某人 → 跳回实录全字段
```

### 两层铁律

| | 实录层 | 谱牒层 |
|---|---|---|
| 数据来源 | 存档原文 | `family.json`（人写 + 导入） |
| 落盘 | **永不** | 正常存取 + 自动备份 |
| 规模 | 全量（几千 ~ 上万） | 精选（几百 ~ 上万） |
| 视图 | 人物 · 世界 | 家谱 · 时间轴 · 表格 |

### 功能一览

- **实录层**：人物页（筛选 / 排序 / 余寿 / 身份标签 / 详情卡 / 双向桥）· 世界页（全表族分类浏览与字段说明）
- **谱牒层**：家谱树（代际模式）· 时间轴（时间模式）· 表格（批量编辑）· 小传生成 · 撤销/重做
- **桥**：立即入谱（连同男性后裔写进谱牒）· 预约入谱（记入续谱名单）· 查档 · 世系速览
- **续谱**：选实录槽 → 演习（只分析不落盘）→ 写回（增量续写，保护手改字段）
- **全史存档**：32 个剧本存档抽取合并为一部总谱（13,000+ 人）
- **推定世系**：虚接（推定父子）/ 挂靠（同代人）/ 史料落定，三类边分线渲染
- **编号映射**：政策 1637 条、能力全量收口、特质/神系等（优先由存档反解，宁缺勿猜）
- **导出**：单文件 HTML 家谱（可发手机离线查阅）· 打包 exe
- **平板端**：PC 侧只读 HTTP 服务 + Kotlin Compose 前端

## 快速开始

### 环境

- **Windows** + **Python 3.10+**（需带 `tkinter`，官方安装包默认包含）
- 核心运行**零第三方依赖**（纯标准库）
- 可选依赖：
  - `Pillow` —— 画布导出图片
  - `requests` —— AI 截图识别（调用豆包 / DeepSeek API）
  - `easyocr` —— 本地 OCR（可选替代）

```bash
pip install Pillow requests          # 可选
```

### 运行

```bash
python main.py
```

或直接双击 **`Start.bat`**（会自动查找可用的 Python 解释器）。

首次运行后，在顶部「存档」对话框里指定**本地存档目录**（从模拟器拉档或手动拷贝的 `Save_All_N` 文件夹）。仓库不含任何游戏存档与谱牒数据，需自备。

### 从模拟器拉档（可选）

配合 `tools/sync_from_mumu.py`（MuMu 模拟器，adb 端口 16416），或手动把存档目录拷到本机。

## 技术特点

- **纯标准库 GUI**：Tkinter 手写界面体系（`app/widgets/kit.py` 为唯一设计系统出处），无第三方 UI 框架。
- **只读铁律**：实录层没有任何写盘入口；谱牒层一律原子写 + 自动备份。
- **数据口径严格**：编号映射「宁缺勿猜」，不确定的一律标注存疑，不做猜测性填充。
- **按需绘制**：大谱牒画布只绘制视口 ± 半屏，布局结果带缓存；万级节点仍然流畅。
- **DPI 感知**：自动检测系统缩放，界面与画布几何分层换算。
- **可单测的纯逻辑层**：布局 / 时间轴 / 爵称 / 小传等模块不依赖 Tk，可独立测试。
