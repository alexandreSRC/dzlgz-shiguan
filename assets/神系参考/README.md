# 神系参考图 · 来源与用途

这个目录保存的是**游戏内置表**的截图。存档里**不存**神明名、神明效果、
庙宇名——它们只在游戏界面上显示，所以留图备份，防止资料丢失。

## 文件

| 文件 | 内容 |
|---|---|
| `祭祀效果_帝俊神系.jpg` | 游戏内「祭祀选择」界面：**帝俊神系 10 位神及其效果全文**（`app/gods.py` 的 `GODS` 就是逐条抄自这里） |
| `庙宇祭祀界面.jpg` | 庙宇祭祀窗口全貌（神明列表 + 神位） |
| `主祭神明为无.png` | 神系被清零后「主祭神明：无」的状态 |

## 注意

1. 攻略内容为**玩家实测结论**，作者本人声明「官方逻辑改来改去、时效性不保证」。
   **与游戏内实际表现冲突时，一律以游戏为准。**
2. `God_Code`（神祇编号）与神名的**编号对应关系仍未获证据** ——
   界面上只显示神名，看不到编号。所以 `app/gods.py` **只登记名字与效果，
   不做编号映射**（宁缺勿猜）。将来若拿到编号↔名字的对应，补进 `gods.py`。
3. 更完整的机制说明（庙宇容量公式、造神条件、继承规则、清零流程）
   见 `app/gods.py` 的模块注释与常量。
