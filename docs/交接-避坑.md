## 二、十条红线（违反 = 交付被退）

1. **假输入不许当结论** —— 编造的数据/坐标只能验代码分支，**不许**写进汇报。
2. **界面 / 交互 / 性能**改动：结论只能写「**请实测（要测以下 N 点）**」，**不许**说"修好了"。
   无头验证通过 ≠ 功能可用（本会话连栽四次）。
3. 说「**对齐 X**」之前，先把 X 的实现读出来、**逐参数列表比对**（不是"看起来像"）。
4. **时间演化只能同槽两点比**（`Save_All_N` ↔ 它的 `.bak_*`）；**跨档 = 不同局**，不可当时间线。
5. **纯计算不许放进绘制 / 拖拽 / 悬停 / 定时回调**；要缓存，且**缓存键必须含全部影响结果的输入**。
6. 改函数**先读签名**；改完 **编译 + 守卫 + AST 三件套**。
7. 字典 / 集合做键一律用 **ID / 编号**；名字只做显示，**允许重复**。
8. **换数据来源**时，回头审原路径的**隐式不变量**（例："成员必在 `positions` 里"）。
9. 删 / 移 / 还原文件：**先 `Test-Path` 复核**（几分钟前的目录清单不作数）；发现少了**只报不还原**、**不推锅**。
10. **性能先量**（7.7ms / 2.3ms / 0.82ms 都是量出来的），不许凭"感觉某处慢"下结论。

## 三、已知地雷（本轮真踩过，带真因）

| 现象 | 真因 | 一行修法 |
|---|---|---|
| 世系框**整批一个都不画** | 家族成员来自存档名册、未必在布局 `positions` ⇒ `edges_of→positions[m]` **KeyError** ⇒ 被视图 `try/except` 吞掉 | 进 `clusters_of` **之前**按 `positions` 过滤 |
| 同名家族**少一个框**（54→50） | 按**标题**建字典，而标题允许重复 | 按**家族编号 `key`** 建键，`titles=` 另传 |
| 勾了筛选**完全没反应** | 时间轴**布局缓存键只有比例尺** | 缓存键加**筛选指纹** `_filter_sig()` |
| 拖动 / 缩放**卡** | 分组计算在**每帧重绘**路径里 | 视图级缓存（按 people）+ 槽级缓存 |
| 已故名**灰白糊掉** | 我自作主张加的；**代际没有**这做法 | **删掉灰字**，只把「底」压灰 |
| **卒年**不显示 | 推定链**断在第一环**（`extra.Ren_End_Old` 谱牒常缺） | 与年龄/余寿同源 —— 走**实录层 `Profile`** |
| 误判「熊国被灭」 | **跨档**比对当时间线 | 同槽 `.bak_*` 两点比（**31 对**） |
| 误报"文件是别的 agent 删的" | 越界替使用者下判断 | **只报不还原**，问一句 |
| 破代码：调用**不存在的方法** | 改函数时**猜签名**（编辑没中） | 读真实签名 + **AST 验证**定义存在 |
| 拖动画布左半浮出**幽灵菜单栏** | T2 快照误用 `capture_widget`（GA_ROOT 整窗截图）原样贴进画布 | `capture_widget_region`：PrintWindow 抓画布自身 HWND，快照前先裁到画布 |
| 拖动**闪现**（快照反复拆建） | ①拖动触发的滚动回调也 arm 了 300ms 自拆定时器 ②补画泵残帧叠画到快照上 ③抓图 update() 重入 | `_grab_dragging` 按住不拆 + `_grab_busy` 防重入 + 进快照先停泵 |
| 松手后**抖动**（≈1s 重组） | 松手即删快照 → 瓦片式补画整幅重组 | **垫底图**：快照转 underlay，真图元画在图上方，补完才删 |
| 大步拖**回退半步** | 平移按「与按下点绝对差」算目标，外来滚动（误触滚轮/触控板惯性）被下一事件拽回 | **增量平移**（按上一事件位置差）+ 拖动中忽略滚轮 |
| 拖远**露纸底** | 快照只覆盖抓取瞬间一屏 | **瓦片预渲染环**：停手后台把视口 ±1 屏铺成位图，拖动=拖图（续五十九/六十） |
| PrintWindow **"成功"却给黑图** | 刚映射的窗口 DWM 表面未就绪（头一帧没合成） | 常驻映射不 withdraw + 黑图 sleep 50ms 重试 + 影子抓图 `allow_screen=False` 禁屏幕兜底 |
| **瓦片里抓出主窗口/游戏画面** | 黑图触发屏幕 BitBlt 兜底，抓到盖在别处的内容 | 同上——影子路径禁用屏幕兜底，宁缺毋错 |
| **时间家谱永远没有瓦片** | 预铺触发只挂补画泵完成，而时间首屏走 `redraw()` 全量同步路径 | 预铺触发双挂：redraw 尾部 + 泵完成 |
| **每次点击清空瓦片缓存** | 作废点挂在 `redraw`，而选中变化也调 redraw（瓦片不烙高亮，无需作废） | 作废点按语义挪到 `rerender`/`set_scale`/Configure + `_tiles_check_lay` 保险 |
| Git Bash 里 robocopy **静默失败** | 正斜杠路径被吞、退出码被 `>/dev/null` 盖住 | 大拷贝用 `cp -a`，或 robocopy 后显式查退出码 |
| **后世头衔被当现职上色**（刘盈＝汉惠帝 → 帝色红框，**反复报过**） | `note`（尊号）里装的是游戏**预置 / 后世**的谥号（尚未即位也写了「汉惠帝」），而 `jue.tier_for` ④ 支（秦及以后）拿它**兜底当爵位** | 新增 `jue._zunhao_live()`：尊号里的「帝/王」**须与本人朝代相符**才算数；本档有**继位记录 / `fief_gen>0` / 天子世系**者豁免（只挡帝/王，公侯伯子男不设闸）。实测四本谱只动刘盈 1 人 |
| 家族框**颜色突然变帝红** | 家族框色取**族内最高爵位**（`layout.state_group_boxes`）⇒ 被上面那条上色错误带出来 | 修上色判据即自动恢复（刘氏框回到「公」紫） |
| 画布上**兄弟次序"错"**（长子排到弟弟右边） | `layout._sib_key` **只认 `birth`**；**无生年的人全落同一键 ⇒ 回落存档文件顺序**。若画布那个 app 实例是**导入前的旧数据**（导入**不触发重载**），就会看到未排序的顺序 | 先核 `children[父]` 与 `positions` 的 x **再下结论**；数据缺生年时"次序＝存档序"是**正常回退不是缺陷** ⇒ 让使用者**重载谱牒 / 重开画布**复看（查 `Get-Process pythonw` 的启动时间 vs 导入时间） |

## 四、口径（**别自己发明**）

- **家族框标题**：公室「X国公族」· 宗室「X国」· 卿室「X国Y氏」· 无国「Y氏」；**禁止 `·` 符号**。
- **世系框**：**一世系一个框**（不分簇）。`clusters_of` 里老的分簇逻辑被一行 `return` 停用，**勿删**（要复原就删那行）。
- **已故**：一律**压灰**；爵位改由**四边描边**表达。
- **高亮**：只认**手动选定** `selected_people`；后裔按 `focus_set()` 一并算。
- **只读保护档**：《全史存档》《上古时代》《文王治岐》**不写**。
- 文案要**古朴**（禁 `·` 这类现代符号）；界面见记忆 `ui_rules`。
